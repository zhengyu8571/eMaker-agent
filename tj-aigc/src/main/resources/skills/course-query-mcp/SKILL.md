description: 使用MCP查询真实课程候选和课程详情，适合明确要求远程查询的单目标课程咨询
---
通过MCP课程服务回答课程名称、价格、有效期、适用人群和介绍。只有课程名称时先搜索候选，再使用返回的courseId查询详情；有歧义时先询问用户。此Skill不开放本地课程工具，也不创建订单。MCP查询失败时明确说明无法核验，不编造实时课程信息。一般课程咨询使用DIRECT，只有需要多步依赖和综合判断时使用PLAN。

严格区分接口值与业务结论：price=0可能是原始价格缺失时的兜底，只能报告接口当前返回0元，不能保证免费、限时免费或活动状态。validDuration单位是月，起算规则必须有接口证据。若适用人群或详情仅为“适用人群”“课程详情”等占位文字，就说明暂无可核实内容，不自行推断课程定位、难度、教师或大纲。仅有课程工具结果时，不生成知识库的[S编号]引用。
