# 构建与配置

[返回项目首页](../README.md)

## 构建

需要 JDK 17 与 Maven 3.6+。根目录编译：

```shell
mvn -DskipTests compile
```

构建 AI 服务及其依赖：

```shell
mvn -pl tj-aigc -am -DskipTests package
```

## 运行依赖

| 依赖 | 用途 |
| --- | --- |
| Nacos | 服务发现、共享配置与提示词 |
| MySQL | 业务数据、会话元数据、知识库与任务表 |
| 支持向量检索的 Redis | 向量索引、会话与增强记忆 |
| Elasticsearch 7 | 关键词检索与课程搜索 |
| RabbitMQ | 文档索引任务与业务事件 |
| OSS | 原始知识文件存储 |
| 模型服务 | 路由、回答、规划、Embedding 与精排 |

## 配置

- 环境变量参考 [.env.example](../.env.example)，由启动进程或部署系统注入；Spring Boot 不会自动加载该文件。
- Nacos 示例共享配置和提示词位于 [config/nacos](../config/nacos/README.md)。
- 演示签名密钥需自行生成，参考 [config/keys](../config/keys/README.md)。
- AI 增量表结构位于 [knowledge_base.sql](../tj-aigc/src/main/resources/sql/knowledge_base.sql) 和 [chat_record.sql](../tj-aigc/src/main/resources/sql/chat_record.sql)。完整业务运行还需准备相应的天机学堂基础表、用户身份与课程数据。

默认开启 Skill 与统一 Runtime；PLAN、MCP 默认关闭，按所需功能显式开启并配置相应工具和权限。

## 启动

```shell
java -jar tj-aigc/target/tj-aigc.jar --spring.profiles.active=local
```

网关入口为 `POST /ais/chat`，服务内部入口为 `POST /chat`。接口请求示例见 [examples/requests.http](../examples/requests.http)。

此仓库提供代码和公开配置示例，不包含企业真实凭据、生产配置或完整业务数据库。
